# desarrollo-agil
Repositorio para el entregable de desarrollo agil

Este es un sistema SaaS diseñado para optimizar la gestión de reservas en la industria gastronómica.

## Descripción del Proyecto

Esta es una plataforma web desarrollada para resolver las ineficiencias de la gestión tradicional de reservas, como las anotaciones manuales o las llamadas telefónicas. Nuestro objetivo es centralizar la disponibilidad en tiempo real, ofreciendo una solución intuitiva tanto para administradores como para comensales.

### Propuesta de Valor

> "Asegura tu reserva en segundos y optimiza tu servicio de forma inteligente."

---

## Funcionalidades Principales (MVP)

- **Calendario Interactivo:** Selección rápida de fechas y horarios disponibles.
- **Gestión de Ocupación:** Dashboard para administradores con control en tiempo real.
- **Notas Especiales:** Registro de requerimientos, alergias y necesidades especiales.
- **Control de Estados:** Actualización inmediata del estado de las mesas (ocupado/libre).
- **Configuración de Horarios:** Definición de días y bloques de atención.
